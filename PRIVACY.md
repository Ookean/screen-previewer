# Privacy Policy

Screen Preview Tool does not collect, store, or transmit any data.

- **No network activity.** The app makes no internet connections of any kind — no telemetry, analytics, crash reporting, or update checks.
- **No data storage.** Screen captures used for the live preview exist only in memory while the app is running and are never written to disk or saved.
- **No account or personal information.** The app does not require sign-in and does not collect names, emails, or usage data.
- **Local-only window access.** The window-moving feature only reads window titles and positions to let you pick and reposition them — it does not read window content.

Because everything runs entirely on your machine, there is no data for this project to lose, sell, or share.

## Changes

If this policy ever changes (e.g. a future feature adds network access), this file will be updated and the change noted in the release it ships with.
